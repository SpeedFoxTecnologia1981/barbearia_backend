# Barbearia API

## Tecnologias
- Java 21
- Spring Boot 3.4.0
- PostgreSQL
- Spring Security
- JWT
- JPA/Hibernate
- Swagger

## Executar
1. `docker compose up -d`
2. `mvn clean install`
3. `mvn spring-boot:run`

API: http://localhost:8080/api
Swagger: http://localhost:8080/api/swagger-ui/index.html
